SELAT JAKARTA RUN

Game terbang di atas Kepulauan Seribu

Pesawat kecilmu lepas landas dari pantai Jakarta di pagi hari. Terbang ke utara melewati 8 ring di atas laut, lalu mendarat di landasan kecil Pulau Pari.

1. Lepas landas — throttle sudah setengah, tinggal terbang
2. Lewati 8 ring oranye — masing-masing +100 poin
3. Mendarat pelan di landasan Pulau Pari — +500 poin
W / S atau ↑ / ↓ — naik / turun
A / D atau ← / → — belok kiri / kanan
Q / E — kemudi (rudder)
Shift / Ctrl — throttle naik / turun
Spasi — rem udara
Mouse — arahkan pesawat (opsional)
P — jeda   M — suara   R — ulang
Roda mouse — throttle
Jaga kecepatan di atas 80 knot supaya tidak stall. Ikuti panah ring di bawah kompas: ring berikutnya ditandai oranye dan berkedip. Mendekati Pulau Pari, turunkan throttle, jaga kecepatan 60–90 knot, dan sentuh landasan dengan pelan — pendaratan keras merusak pesawat. Jangan menyentuh laut, pulau, atau kota.

JEDA

Pesawatmu menunggu di udara. Lanjutkan misinya.
